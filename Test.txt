1. ¿Qué es un objeto en POO?
Un objeto es una instancia de una clase que puede tener atributos y métodos.
2. ¿Qué es una clase en POO?
Una clase es un modelo para crear objetos que contiene atributos generales de este y métodos.
3. ¿Qué es la encapsulación?
Es la propiedad de proteger los atributos de una clase y darles acceso a ver o modificar con los 
métodos Gets y Sets
4. ¿Qué es la herencia?
La herencia permite crear una nueva clase basada en una clase existente, heredando sus atributos y métodos.
5. ¿Qué es el polimorfismo?
El polimorfismo permite que diferentes clases se traten como instancias de una misma clase a través de una interfaz común.
6. ¿Qué es un método en POO?
Un método es una función definida dentro de una clase que describe el comportamiento de los objetos de esa clase.
7. ¿Qué es un atributo en POO?
Son las características de un objeto estas son las que se usan para poder clasificarlos buscando características similares en varios objetos
